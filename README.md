# mixed-content-unblocker
A chrome extension to unblock/allowed mixed-content 


## For Local Installation (dev)

*ID*
>Gunakan metode "Load Unpacked":
- Buka chrome://extensions/.
- Aktifkan Developer Mode (pojok kanan atas).
- Klik "Load Unpacked" dan pilih folder ekstensi.

*EN*
>Use "Load Unpacked":
- Open chrome://extensions/.
- Activate Developer Mode (Right Up Corner).
- Click "Load Unpacked" and select extension folder.
