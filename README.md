# mixed-content-unblocker
A chrome extension to unblock/allowed mixed-content 


## For Local Installation (dev)

*ID*
gunakan metode "Load Unpacked":
1️⃣ Buka chrome://extensions/.
3️⃣ Aktifkan Developer Mode (pojok kanan atas).
4️⃣ Klik "Load Unpacked" dan pilih folder ekstensi.

*EN*
Use "Load Unpacked":
1️⃣ Open chrome://extensions/.
3️⃣ Activate Developer Mode (Right Up Corner).
4️⃣ Click "Load Unpacked" and select extension folder.
